# Лабораторная работа № 3 — обработка адресных данных

Консольное приложение на Python для анализа адресов зданий из файлов CSV и XML.
Программа находит повторяющиеся записи, выводит количество уникальных записей
для зданий с этажностью от 1 до 5 в каждом городе и измеряет время обработки файла.

## Требования

- Python 3.10 или новее.
- Библиотека `pandas` для чтения CSV.

## Установка и запуск

Откройте терминал в корневой папке проекта, создайте виртуальное окружение
и установите зависимость:

```bash
python -m venv .venv
```

Активируйте окружение в Linux/macOS:

```bash
source .venv/bin/activate
```

Или в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установите `pandas` и запустите программу:

```bash
python -m pip install pandas
python main.py
```

Если в вашей системе Python вызывается командой `python3`, используйте её
вместо `python` при создании окружения.

## Использование

После запуска введите путь к CSV- или XML-файлу:

```text
Введите путь до файла csv/xml или exit: data/address.csv
```

Поддерживаются абсолютные пути, пути относительно текущей рабочей папки
и сокращение `~` для домашнего каталога. Путь нужно вводить без обрамляющих кавычек,
даже если он содержит пробелы.

Программа выводит:

1. Повторяющиеся записи и число вхождений каждой из них, если повторы найдены.
2. Количество уникальных записей для зданий с 1, 2, 3, 4 и 5 этажами в каждом городе.
3. Время обработки файла в секундах.

После обработки можно указать следующий файл. Для завершения введите `exit`.
При неверном пути или неподдерживаемом расширении программа запрашивает путь снова.

## Форматы входных данных

В обоих форматах используются четыре обязательных поля:

| Поле | Значение | Тип |
| --- | --- | --- |
| `city` | Город | Строка |
| `street` | Улица | Строка |
| `house` | Номер дома, включая буквы и дроби | Строка |
| `floor` | Количество этажей | Целое число |

### CSV

Первая строка должна содержать названия столбцов `city`, `street`, `house`, `floor`.
Разделитель определяется автоматически средствами `pandas`.
Пример файла с разделителем `;`:

```csv
city;street;house;floor
Санкт-Петербург;Ленина;1;5
Санкт-Петербург;Ленина;1;5
Москва;Мира;10А;3
```

### XML

Записи должны быть элементами `item`, расположенными непосредственно внутри
корневого элемента. Поля задаются атрибутами:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root>
    <item city="Санкт-Петербург" street="Ленина" house="1" floor="5" />
    <item city="Санкт-Петербург" street="Ленина" house="1" floor="5" />
    <item city="Москва" street="Мира" house="10А" floor="3" />
</root>
```

В этих примерах первая запись встречается два раза, но в статистике
пятиэтажных зданий Санкт-Петербурга учитывается один раз.

## Особенности подсчёта

- Записи считаются одинаковыми только при совпадении всех четырёх полей,
  включая этажность. Регистр и пробелы в строках не нормализуются.
- Повторные вхождения одной записи не увеличивают статистику по этажности.
- Записи с этажностью вне диапазона 1–5 участвуют в поиске повторов,
  но не увеличивают счётчики этажности.
- Данные обрабатываются в памяти: CSV загружается в таблицу `pandas`,
  XML — в дерево элементов. Для больших файлов требуется достаточно оперативной памяти.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Интерактивный цикл, выбор парсера и вывод результатов |
| `path.py` | Ввод пути и проверка существования и расширения файла |
| `fileParser.py` | Абстрактный класс парсера `FileParser` |
| `csvParser.py` | Чтение CSV и подсчёт вхождений записей |
| `xmlParser.py` | Чтение XML и подсчёт вхождений записей |
| `addressRecord.py` | Неизменяемый dataclass адресной записи |
| `count.py` | Подсчёт уникальных записей по городам и этажности |

Входные файлы можно хранить в папке `data/`. Она исключена из Git через
`.gitignore`, поэтому после клонирования репозитория данные нужно добавить
самостоятельно или указать путь к файлам в другой папке.
